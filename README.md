# 🌼 MargueriteMarket — logiciel de caisse

Projet de jeu de rôle pour un faux supermarché de papeterie.

## Fonctionnalités
- Saisie d'un code produit
- Ajout de plusieurs articles
- Quantités + / −
- Suppression d'un article
- Calcul automatique du total
- Paiement simulé : carte, sans contact ou espèces
- Calcul de la monnaie en espèces
- Écran de transaction
- Ticket de caisse fictif
- Numéro de ticket conservé localement
- Fonctionne sans serveur et peut être publié avec GitHub Pages

> Tous les paiements sont fictifs : aucune transaction bancaire réelle n'est effectuée.

## Installation sur GitHub
1. Créer un dépôt, par exemple `margueritemarket-caisse`.
2. Envoyer `index.html`, `styles.css`, `app.js` et `products.js`.
3. Dans **Settings → Pages**, choisir **Deploy from a branch**, puis `main` et `/root`.
4. Ouvrir l'adresse GitHub Pages indiquée par GitHub.

## Modifier les produits
Les produits et leurs codes sont dans `products.js`. Les prix de ce catalogue sont des prix fictifs pour le jeu.
