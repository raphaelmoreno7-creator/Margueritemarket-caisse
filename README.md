# 🌼 MargueriteMarket — Caisse
Logiciel de caisse fictif pour jeu de rôle.

Fonctions : codes produits, panier, quantités, total, paiements simulés, espèces et monnaie, ticket de caisse et carte fidélité fictive.

## Carte fidélité
Au paiement, entre un numéro fictif de 6 à 12 chiffres. Il est affiché sur le ticket sous forme masquée (4 derniers chiffres).
Aucun paiement réel ni aucune donnée bancaire réelle ne sont utilisés.
